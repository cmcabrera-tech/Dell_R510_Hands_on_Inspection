# Evidence and Privacy

The original inspection photographs may expose service tags, component serial numbers, asset labels, network addresses, hostnames, and software license information.

Use a private repository for the complete evidence set. Before publishing a public copy:

1. Remove photographs that show product keys or management-network details.
2. Redact service tags, MAC addresses, serial numbers, and internal asset labels.
3. Check image metadata before release.
4. Keep an unmodified internal evidence archive so the edited public copies do not replace the originals.

No credentials or license keys should be committed to the repository.
