# Next Session Checklist

## Before power-on

- [ ] Confirm authorization to handle any data-bearing drives.
- [ ] Use ESD protection and disconnect both power supplies.
- [ ] Record the current cable and card positions before moving anything.
- [ ] Match each physical RAID adapter to the controller names shown during POST.
- [ ] Inspect the bowed cache or memory module, retaining clips, and socket.
- [ ] Inspect the RAID battery cable and battery for swelling or damage.
- [ ] Check that all SAS and power connectors are fully seated.
- [ ] Confirm the installed DIMM population against Dell's supported R510 layout.

## Controlled startup

- [ ] Capture a complete POST video or ordered photo sequence.
- [ ] Record H700 and H800 firmware versions and status separately.
- [ ] Enter each PERC utility without changing configuration.
- [ ] Photograph physical-disk, foreign-configuration, and virtual-disk screens.
- [ ] Export or photograph the system event log and hardware inventory.
- [ ] Run Dell diagnostics for memory, storage controllers, fans, and power supplies.

## Data protection

- [ ] Do not initialize disks.
- [ ] Do not clear foreign configurations.
- [ ] Do not create or delete virtual disks.
- [ ] Do not update controller firmware until the existing array state and recovery risk are understood.

## Completion record

- [ ] Write down each action in the order performed.
- [ ] Record whether each error changed after a specific action.
- [ ] Preserve the original photos and diagnostic output.
- [ ] Update the project with confirmed results, not memory or assumptions.
